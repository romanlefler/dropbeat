# General Settings

## Popup

- Progress Bar: Show playback progress in the popup card. This does require an animation, however it only runs when the card is actually open. Defaults to show.

## Keybindings

- Desktop Shortcut: Desktop keyboard shortcut to open or close the card. Default is no shortcut.
- Include Super Key?: Optionally insert the Super key into the desktop shortcut above. This is necessary because the widget will not record a Super press.

## Fullscreen

- Monitor: Select the monitor used for the fullscreen window, or select *Auto* to choose automatically. Default is Auto.
- Hide Cursor: Hide the cursor in the fullscreen window. Default is to show the cursor.

## Behavior

- Hide Browsers: Don't show web browsers like Firefox, Brave, etc. Useful if you may have YouTube or other media open and also a music player, but just want to show the music. Default is to show web browsers.

## Internet

- Fetch Album Covers: Allow fetching album covers over HTTP or HTTPS. Defaults to allow.
- HTTPS Only: Block album cover connections over plain HTTP. This setting is available when *Fetch Album Covers* is enabled. Defaults to HTTPS only.
- Request Timeout: Set the album cover request timeout in seconds. This setting is available when *Fetch Album Covers* is enabled. Defaults to 10 seconds.
